Агент не запускается
--------------------

* Запустите CLI агента вручную в терминале. Если он не работает там, проблема связана с установкой или авторизацией, а не с Orca.
* Убедитесь, что CLI находится в доступном Orca `PATH`, и проверьте [Настройки → Агенты](/docs/reference/settings).
* Нажмите **Перезапустить** на вкладке.

Diff не обновляется или выглядит неправильно
--------------------------------------------

* Нажмите кнопку обновления на панели diff.
* Внешние операции Git, включая rebase и reset, могут попасть между обновлениями.

Не создаётся worktree
---------------------

* Исходная ссылка могла быть не загружена. Выполните `git fetch origin`.
* Для ветки уже может существовать worktree. Удалите его или выберите другое название ветки.

Orca CLI сообщает `command not found`
-------------------------------------

Зарегистрируйте CLI в разделе [Настройки → Экспериментальные функции → CLI](/docs/reference/settings). В macOS устанавливается прокладка в `~/.local/bin`; каталог должен входить в `PATH`.

Браузер сообщает `browser_no_tab`
---------------------------------

В текущем worktree нет вкладки браузера. Выполните `orca tab create --url ...` или откройте панель браузера вручную.

Производительность и память
---------------------------

* Закрывайте неиспользуемые worktree: каждый поддерживает наблюдатели файлов.
* Больше всего памяти занимают разделённые панели с множеством вкладок браузера.

Ошибки GitHub
-------------

Лимиты, авторизация `gh`, недостающие разрешения и доступ к репозиторию влияют на управление версиями и проверки pull request. Полная таблица приведена в статье [Ошибки GitHub](/docs/reference/github-errors).

```
gh auth status -h github.com
gh api user
gh api rate_limit --jq '.resources.core'
```

Журналы
-------

Команда **Справка → Открыть журналы** показывает каталог журналов Orca. Прикладывайте их к отчёту об ошибке.
