title: "Справочник настроек"
description: "Разделы настроек Orca и доступные в них параметры."
---

Настройки разделены на панели. Откройте поиск сочетанием `Cmd-,` и введите ключевое слово.

Общие
-----

* Регистрация Orca CLI.
* Проверка обновлений. `Shift` включает RC, а `Cmd` в macOS или `Ctrl` в Windows и Linux проверяет сборки с меткой производительности.
* Масштаб интерфейса.
* Стандартное название нового worktree.

Оформление
----------

Тема, акцент, плотность, шрифты интерфейса и редактора, мини-карта, строка состояния, значок приложения и язык. Интерфейс поддерживает системный язык, английский, упрощённый китайский, корейский, японский и испанский.

Git
---

Базовая ссылка, подпись коммитов, внешний редактор Git, автоматическое переименование веток и **Бюджет GitHub API** для REST, Search и GraphQL. Если показатели не объясняют ошибку, см. [Ошибки GitHub](/docs/reference/github-errors).

Терминал
--------

Шрифт, тема, курсор, отступы, импорт Ghostty и Warp, преобразование клавиши JIS Yen в обратную косую черту и стандартная оболочка Windows.

Быстрые команды
---------------

Сохранённые команды терминала с глобальной или проектной областью и фильтрами списка.

Агенты
------

Обнаруженные и пользовательские агенты, видимость в меню запуска, режимы разрешений **Yolo** и **Ручной**, аккаунты Claude и Codex и хуки запуска.

Браузер
-------

[Профили](/docs/browser/profiles), масштаб новых вкладок, параметры режима дизайна и инструменты разработчика.

Интеграции
----------

GitHub OAuth, Linear, Jira, MiniMax и серверы MCP. Для Jira указываются сайт, почта и токен; для MiniMax можно добавить cookie с `platform.minimax.io/console/usage`.

Уведомления
-----------

Системные, звуковые и встроенные уведомления о завершении агента, пользовательские звуки, ошибки проверок pull request и обновления.

Голос
-----

Ключ OpenAI API для облачного распознавания речи хранится локально и используется только API транскрибации.

SSH
---

Удалённые worktree, узлы, пароли ключей и стандартный файл идентификации.

Удалённые серверы Orca
----------------------

Подключение удалённых сред, публикация приложения как сервера, отзывные ссылки доступа и выбор стандартной среды.

Сочетания клавиш
----------------

Все команды переназначаются. Для показа спящих рабочих пространств стандартного сочетания нет. Закрытие всех вкладок редактора использует `Cmd+Option+W` в macOS и `Ctrl+Alt+W` в Windows и Linux.

Репозиторий
-----------

Базовая ссылка, хуки, команды создания worktree, значки на боковой панели и рецепты ИИ для сообщений коммитов, pull request и названий веток.

Экспериментальные функции
-------------------------

[Лента агентов](/docs/reference/activity), компактные карточки, [гибернация](/docs/agents/hibernation), [среды для отдельных рабочих пространств](/docs/reference/ways-to-run#4-per-workspace-environments-ephemeral-vms) и другие нестабильные функции.
