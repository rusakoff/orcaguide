Приложение Orca для iOS и Android подключается к настольной версии и позволяет следить за агентами: смотреть состояния и историю терминала, отвечать на вопросы, усыплять worktree, проверять Git и менять аккаунты. Подключение выполняется один раз, а настольная Orca остаётся источником данных.

Бета-версия

Установите iOS из [App Store](https://apps.apple.com/us/app/orca-ide/id6766130217), подключитесь к [TestFlight](https://testflight.apple.com/join/YjeGMQBA) или скачайте [APK для Android](https://github.com/stablyai/orca/releases/download/mobile-android-v0.0.32/app-release.apk).

Возможности
-----------

* Общий список worktree со всех локальных и удалённых серверов, агентов и состояний.
* Полное дерево файлов, включая вложенные каталоги.
* Загрузка недавней истории терминала, выделение, копирование и вставка.
* Дополнительные клавиши `Tab` и `Shift+Tab`, а также режим **Live** для прямого ввода.
* Ответы агенту, прикрепление фото и файлов и диктовка. В режиме Live распознанный текст вставляется без автоматического `Return`.
* Браузер в режимах **Web** и **Mobile**.
* Проверка изменений Git, добавление в индекс и коммит.
* Смена аккаунта агента и просмотр лимитов.
* Создание рабочего пространства из GitHub, Linear, GitLab, ветки или названия.
* Push-уведомления, соответствующие [настольным уведомлениям](/docs/reference/notifications).

Мобильное приложение является пультом управления, а не полноценным редактором.

Подключение
-----------

1. Откройте подключение в меню аккаунта или состояния настольной Orca и получите одноразовый код.
2. В приложении выберите **Подключить** и вставьте код либо откройте глубокую ссылку.
3. Телефон и компьютер обмениваются данными напрямую, после чего используется токен устройства.

При закрытии настольного приложения соединение обрывается, поскольку облачного ретранслятора нет. После запуска телефон подключается автоматически.

Аккаунты
--------

Мобильный переключатель повторяет настольный и показывает использование неактивных аккаунтов и время сброса лимитов. Смена действует на подключённом компьютере.

Создание рабочего пространства
------------------------------

На экране **Создать рабочее пространство** выберите источник. **Smart** ищет среди поддерживаемых провайдеров и веток, остальные варианты ограничивают поиск. В разделе **Дополнительно** задаются название и ветка.

Управление версиями
-------------------

Нажмите значок ветки, чтобы просмотреть изменения, добавить или убрать файлы из индекса и создать коммит. Существующий pull request GitHub можно связать через **Привязать существующий PR**.

Браузер
-------

Переключатель **Web / Mobile** показывает обычную страницу или запрашивает у настольного браузера мобильный размер области просмотра.

Настройки терминала
-------------------

* **Размер текста:** от 50% до 200%, отдельно для устройства. Масштабирование жестом сохраняет ближайшее значение.
* **Автодополнение и автокоррекция:** по умолчанию выключены, чтобы ОС не меняла команды, параметры и пути.

Устранение неполадок
--------------------

* Если worktree постоянно показывает загрузку, принудительно обновите строку для синхронизации heartbeat.
* Если подключение не удаётся, создайте новый код: старый истекает через несколько минут.

Свяжите мобильные сигналы с [настольными уведомлениями](/docs/reference/notifications), чтобы получать завершения на нужном устройстве.
