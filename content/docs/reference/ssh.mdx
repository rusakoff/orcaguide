Orca может запускать агентов на удалённых компьютерах по SSH. Это удобно для долгих сборок, серверов с GPU и задач, которые не стоит выполнять на ноутбуке.

Один из четырёх режимов

SSH является одним из способов удалённых вычислений. Локальный запуск, собственные серверы и временные виртуальные машины описаны в статье [Способы запуска Orca](/docs/reference/ways-to-run).

Удалённый worktree по SSH: агенты работают на сервере, редактор и diff остаются локальными

Добавление узла
---------------

1. Откройте [Настройки → SSH](/docs/reference/settings).
2. Укажите адрес, пользователя, порт и при необходимости ключ. Orca также импортирует узлы из конфигурации OpenSSH и файлов `Include`.
3. Для защищённого паролем ключа Orca запросит пароль при первом подключении.
4. Нажмите **Проверить**.

Использование
-------------

При создании worktree выберите узел SSH вместо локального компьютера. Orca создаст git worktree на сервере, запустит там агентов и синхронизирует события файлов для локальной работы редактора и diff.

Дополнительные параметры
------------------------

В редакторе узла раскройте **Дополнительное подключение** для прокси, промежуточного узла и мультиплексирования. По умолчанию повторно используется соединение OpenSSH в macOS и Linux. Отключайте это только для серверов, запрещающих совместные сессии.

Пароли ключей
-------------

Пароли хранятся в памяти до закрытия Orca. В настройках SSH можно увеличить срок хранения.

Состояние
---------

Зелёный индикатор означает подключение, жёлтый повторное соединение, красный отключение. Разрыв не завершает агента: Orca подключится снова. Состояния агента передаются по SSH и видны в [ленте агентов](/docs/reference/activity).

Сессии после закрытия
---------------------

Закрытие приложения не завершает удалённые PTY. Ретранслятор на сервере удерживает их, а после открытия Orca возвращает вкладки и историю. Период ожидания по умолчанию равен пяти минутам и настраивается для узла.

Загрузка файлов
---------------

В контекстном меню файла выберите **Загрузить**, чтобы сохранить его на ноутбуке. Действие доступно только в настольном приложении и использует системный диалог. Каталоги сначала нужно архивировать или копировать через терминал.

Перенаправление портов
----------------------

Вкладка **Порты** на правой панели (`Cmd+Shift+I`) находит прослушиваемые порты через `/proc/net/tcp`. Их можно перенаправить одним нажатием, добавить вручную или удалить. Правила сохраняются после перезапуска и повторного подключения. Привилегированные порты автоматически получают локальный номер, например 80 превращается в 10080.
