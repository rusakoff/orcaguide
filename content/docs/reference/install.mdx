Orca доступна для macOS, Windows и Linux.

Загрузка
--------

* **macOS:** [Apple Silicon](https://github.com/stablyai/orca/releases/latest/download/orca-macos-arm64.dmg) или [Intel](https://github.com/stablyai/orca/releases/latest/download/orca-macos-x64.dmg).
* **Windows:** [установщик](https://github.com/stablyai/orca/releases/latest/download/orca-windows-setup.exe).
* **Linux:** [AppImage](https://github.com/stablyai/orca/releases/latest/download/orca-linux.AppImage) или [.deb](https://github.com/stablyai/orca/releases).
* Старые версии: [GitHub Releases](https://github.com/stablyai/orca/releases).

### Homebrew в macOS

Стабильные выпуски публикуются как cask Homebrew:

```
brew install --cask stablyai/orca/orca
```

Команда `brew upgrade --cask orca` устанавливает новую стабильную сборку. Для RC используйте GitHub Releases или проверку обновлений внутри приложения.

Первый запуск
-------------

Orca запросит доступ к домашнему каталогу для добавления репозиториев, предложит импортировать `~/.claude`, `~/.codex` и настройки Ghostty, затем откроет экран добавления первого репозитория.

Обновления
----------

По умолчанию Orca автоматически обновляется по стабильному каналу. RC-сборки получают новые функции раньше и могут выходить ежедневно.

Постоянного переключателя RC нет. Удерживайте `Shift` при нажатии **Проверить обновления** в разделе [Настройки → Общие → Обновления](/docs/reference/settings), чтобы разово включить предварительные версии, либо скачайте сборку из GitHub Releases.

Если обновление не подходит

Старые версии доступны на странице выпусков. Возврат к ним не приводит к принудительному откату данных worktree.

Особенности платформ
--------------------

### macOS

Приложение подписано и нотариально заверено. При первом запуске macOS может запросить подтверждение, что нормально для Electron.

### Windows

PowerShell или CMD выбирается в разделе [Настройки → Терминал](/docs/reference/settings). Большинству пользователей подойдёт PowerShell.

### Linux

Доступны сборки AppImage и `.deb`; подробности приведены на странице выпусков.
