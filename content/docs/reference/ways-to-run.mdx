title: "Способы запуска Orca"

Worktree можно запустить локально, на узле SSH, постоянном сервере команды или в отдельной облачной виртуальной машине.

Краткое сравнение
-----------------

Режим

Где работают файлы и агенты

Для чего подходит

**Локальный**

Ваш компьютер

Повседневная разработка и быстрые итерации

**SSH**

Удалённый узел под вашим управлением

Серверы разработки, GPU и постоянные VPS

**Удалённый сервер Orca**

Компьютер с Orca или `orca serve`

Общая постоянная среда, мобильное управление и автоматизация

**Среда отдельного worktree**

Одноразовая виртуальная машина или песочница

Изолированные временные вычисления

Orca не продаёт управляемый VPS. Удалённые режимы используют ваши машины и облачные аккаунты.

1\. Локальный компьютер
------------------------

Установите Orca, откройте проект и создавайте worktree. Агенты, терминалы и браузер работают рядом с интерфейсом.

![Worktree на локальном Mac](https://www.onorca.dev/docs/ways-to-run-local-sidebar.png)

Это стандартный вариант. Начните с [первой сессии](/docs/reference/first-session) и статьи [Worktree](/docs/model/worktrees).

2\. Узлы SSH
------------

Подключите Mac mini, Linux VPS, GPU-сервер или облачную песочницу с SSH. При создании worktree выберите узел в поле **Запустить на**. Агенты и Git работают удалённо, редактор и интерфейс остаются на ноутбуке.

![Выбор локального или удалённого места запуска worktree](https://www.onorca.dev/docs/ways-to-run-run-on.png)

Этот режим подходит, если на сервере уже есть репозиторий, инструменты и учётные данные. Добавьте узел в [Настройки → SSH](/docs/reference/settings), проверьте соединение и выберите его при создании worktree. Подробнее: [Worktree по SSH](/docs/reference/ssh).

3\. Удалённые серверы Orca
--------------------------

Оставьте Orca на собственном ноутбуке, Mac mini, домашнем сервере, VPS или общей машине. Сервер владеет проектами, worktree, терминалами и агентами, а ноутбук, браузер и телефон служат клиентами.

Режим подходит, если агенты должны переживать сон ноутбука, мобильное приложение должно возвращаться к тем же сессиям или автоматизации нужен постоянный узел.

Проще всего установить Orca и Tailscale на обе машины, создать ссылку в **Настройки → Удалённые серверы Orca → Опубликовать это приложение как сервер** и добавить её на клиенте. Для сервера без интерфейса:

```
orca serve --pairing-address <доступный-tailscale-ip-или-hostname>
```

Подробнее: [Удалённые серверы Orca](/docs/reference/remote-servers).

SSH использует удалённую машину для выбранных worktree, но средой владеет ноутбук. Удалённый сервер Orca хранит полное состояние и допускает несколько клиентов.

4\. Среды для отдельных worktree
--------------------------------

Каждый worktree может запускать отдельную облачную песочницу, виртуальную машину или контейнер Docker по рецепту из репозитория (`orca.yaml` и сценарии жизненного цикла). Создание запускает среду, а приостановка, возобновление и удаление управляют ею. Провайдер, образы и оплата остаются вашими.

Используются Vercel Sandbox, Fly, Modal, обычные узлы SSH и локальный Docker. Рецепт подключается через сервер Orca или возвращает параметры SSH.

![Настройка сред для отдельных worktree](https://www.onorca.dev/docs/ways-to-run-per-workspace-env.png)

Включите функцию в [Настройки → Экспериментальные функции](/docs/reference/settings), установите соответствующий навык и попросите агента:

```
Use the orca-per-workspace-env skill to set up a per-workspace environment for this repo.
```

Навык проверит зависимости, базовый снимок, авторизацию агента, рецепт `orca.yaml` и диагностику. Рецепт появится при создании worktree только после добавления `environmentRecipes` в `orca.yaml` основной рабочей копии проекта.

Это не VPS Orca

Вы самостоятельно выбираете и оплачиваете провайдера. Orca выполняет сценарии создания, приостановки, возобновления и уничтожения и подключается по URL или SSH.

Как выбрать
-----------

* **Локально**, если ноутбук достаточно быстр, а агенты работают недолго.
* **SSH**, если уже есть сервер и не нужна вторая среда Orca.
* **Удалённый сервер Orca**, если нужен постоянный общий runtime для мобильного приложения, браузера и автоматизаций.
* **Среда worktree**, если каждой задаче нужна чистая одноразовая песочница.

Режимы можно сочетать в одной установке.
