---
title: "Первая сессия с тремя агентами"
description: "От пустого приложения до трёх параллельных агентов и готового pull request за пять минут."
---

За несколько минут вы запустите трёх агентов с разными подходами к одной задаче и отправите лучший результат в pull request.

![Три агента в разделённых панелях, по одному на каждый worktree](https://www.onorca.dev/whats-new/posters/orca-split-screen.jpg)

Три агента в разделённых панелях, по одному на каждый worktree

1\. Добавьте репозиторий
------------------------

Нажмите **Добавить репозиторий** на боковой панели и выберите локальную рабочую копию. Orca прочитает состояние Git и назначит стандартную ветку **базовой ссылкой**, от которой создаются новые worktree. Позже её можно изменить в настройках репозитория.

2\. Создайте worktree
---------------------

Нажмите **+** рядом с названием репозитория и введите название задачи, например `fix-login-race`. Если оставить поле пустым, Orca выберет название морского животного.

![Окно запуска рабочего пространства с выбором агента или пустого терминала](https://www.onorca.dev/whats-new/posters/default-agent-opening.jpg)

Окно запуска рабочего пространства с выбором агента или пустого терминала

В окне заранее выбран [агент по умолчанию](/docs/reference/settings). Вместо него можно открыть пустой терминал. Закреплённые worktree выделяются на боковой панели.

Выберите исходную ссылку. Обычно это базовая `origin/main`, но можно начать с любой ветки или коммита. Orca создаст настоящий git worktree в управляемом каталоге, откроет ветку и рабочее пространство.

3\. Выберите агента
-------------------

В терминале нового worktree откройте список агентов и выберите Claude Code, Codex, Cursor CLI или другой [поддерживаемый агент](/docs/agents/supported). Orca запустит CLI с правильным рабочим каталогом и учётными данными подписки.

4\. Запустите три решения одной задачи
--------------------------------------

Повторите шаги 2 и 3 ещё два раза:

* `fix-login-race` для Claude Code;
* `fix-login-race-2` для Codex;
* `fix-login-race-3` для Cursor CLI.

Отправьте всем одинаковый запрос и дождитесь трёх вариантов в отдельных ветках.

5\. Разделите панели
--------------------

Перетащите вкладку worktree к правому или нижнему краю панели, чтобы наблюдать за всеми агентами. Подробнее: [Вкладки и панели](/docs/model/tabs-panes-splits).

6\. Выберите результат и отправьте его
--------------------------------------

Откройте diff каждого worktree. Оставьте замечания через [Комментарии к изменениям ИИ](/docs/review/annotate-ai-diff) и отправьте их лучшему агенту.

Создайте коммит и отправьте ветку из Orca по инструкции [Коммит и отправка](/docs/review/commit-push). Два оставшихся worktree можно удалить вместе с ветками одним нажатием.

Готово

Добавить репозиторий, создать worktree, запустить агента, разделить панели, проверить diff и отправить результат. Остальная документация подробнее раскрывает эти этапы.
