Раздел **Агенты** на боковой панели открывает общую хронологическую ленту событий всех worktree: завершения, блокирующие вопросы, непрочитанные ответы и создание worktree. Она дополняет [уведомления](/docs/reference/notifications) отдельных worktree и позволяет разбирать события в одном месте.

Лента включена по умолчанию. Новые события отмечаются счётчиком непрочитанных. Нажатие переводит к нужному worktree и панели, как при переходе из системного уведомления.

Для перехода к фильтру ленты нажмите `Cmd+F` в macOS или `Ctrl+F` в Windows и Linux. Если фокус находится во встроенном терминале, сочетание продолжает управлять поиском терминала.

Содержимое ленты
----------------

В ленте появляются:

* завершение хода агента, переход в ожидание или блокирующий вопрос;
* создание нового worktree;
* агент, слишком долго ожидающий ввода;
* краткий фрагмент последнего ответа для просмотра без открытия обсуждения.

События группируются по состоянию. Работающие агенты закреплены сверху, поэтому их видно сразу.

Связь с уведомлениями
---------------------

Лента не заменяет [колокольчик в заголовке](/docs/reference/notifications) и системные уведомления о завершении агента. Она нужна после долгого отсутствия: вместо просмотра каждого worktree достаточно пройти по общей ленте.
