---
title: "Браузер для каждого worktree"
description: "Встроенный Chromium с отдельными вкладками и состоянием для каждого worktree."
---


У каждого worktree есть отдельное окно Chromium с адресной строкой, историей и инструментами разработчика. Вкладки относятся только к текущему worktree и не смешиваются с остальной работой.

![Панель браузера отдельного worktree с адресной строкой и вкладками](https://www.onorca.dev/whats-new/posters/orca-design-mode.jpg)

Управление
----------

* Адресная строка с историей и нечётким поиском по URL.
* Кнопки перехода назад и вперёд, перезагрузки и остановки загрузки.
* `Cmd-F`: поиск на странице.
* `Cmd-T`: новая вкладка в текущем worktree.
* `Cmd-Shift-T`: повторное открытие последней закрытой вкладки.

Привязка к worktree
-------------------

Для каждого worktree отображается свой набор вкладок. При переключении между worktree Orca восстанавливает соответствующие вкладки браузера и положение прокрутки.

![Вкладки браузера с сохранением сессий для каждого worktree: одним нажатием можно импортировать файлы cookie из Chrome или Edge и сохранить вход в аккаунты](https://www.onorca.dev/whats-new/posters/browser-2-demo.jpg)

Загрузки
--------

Текущие и недавно завершённые загрузки отображаются на панели под строкой инструментов. Незавершённую загрузку можно отменить, готовый файл открыть или показать в его папке, а ненужную строку убрать из списка.

Эмуляция размера области просмотра
----------------------------------

Для вкладки можно задать собственный размер области просмотра и проверять адаптивную вёрстку, не меняя размер всей панели. Orca использует эмуляцию устройств через Chrome DevTools Protocol, поэтому страница получает заданные размеры в `window.innerWidth` и медиазапросах.

Автоматизация
-------------

Агенты могут управлять браузером через [Orca CLI](/docs/cli/overview), используя команды `orca snapshot`, `orca click`, `orca fill` и другие. Команды работают с тем же браузером, вкладками и сессией, которые видит пользователь.

![Агент управляет встроенным браузером Orca через CLI, используя те же вкладки и сессию](https://www.onorca.dev/whats-new/posters/orca-browser-use.jpg)
