Linear находится рядом с провайдерами проверки кода на панели задач. Задачи Linear можно просматривать, создавать, изменять и связывать с worktree так же, как задачи GitHub.

Настройка
---------

1. Откройте [Настройки → Интеграции → Linear](/docs/reference/settings).
2. Вставьте личный токен API из раздела [Linear → Settings → API](https://linear.app/settings/api).
3. Выберите нужные команды.

Работа с Linear
---------------

* Панель задач показывает задачи GitHub и Linear в одном списке.
* При создании worktree из задачи Linear название заполняется автоматически, а идентификатор задачи привязывается к worktree.
* В карточке задачи можно менять состояние, исполнителя, приоритет, метки и оценку. Приоритет отображается значками Linear.
* При запуске агента из задачи Linear Orca добавляет в контекст встроенные изображения и другие материалы из описания, комментариев и подзадач. Агент видит макет или воспроизведение ошибки без ручного копирования снимков.
* В длинных списках доступна кнопка **Загрузить ещё**.
* Orca запоминает последний источник задач для каждого репозитория: GitHub, Linear или Jira.

Синхронизация состояния Linear, например перевод задачи в "В работе" при создании worktree, включается отдельно для каждой команды.
