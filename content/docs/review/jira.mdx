title: "Панель задач Jira"
description: "Просмотр, изменение и привязка задач Jira Cloud к worktree."
---

Задачи Jira Cloud можно просматривать, изменять и связывать с worktree так же, как задачи Linear или GitHub.

Jira находится рядом с GitHub и Linear на панели задач. Работайте с задачами Jira Cloud и создавайте из них worktree, не покидая Orca.

Подключение сайта Jira
----------------------

1. Откройте раздел **Задачи** на боковой панели и выберите **Jira**. Этот источник виден рядом с GitHub и Linear ещё до сохранения учётных данных.
2. Нажмите **Подключить Jira**. Откроется окно подключения сайта.
3. Заполните три поля:
   * **URL сайта Jira Cloud**, например `https://example.atlassian.net`;
   * **электронная почта Atlassian**;
   * **токен Atlassian API**, который создаётся в разделе [id.atlassian.com → Security → API tokens](https://id.atlassian.com/manage-profile/security/api-tokens).
4. Нажмите **Подключить**. Orca проверит данные и загрузит доступные сайты.

Можно подключить несколько сайтов Atlassian. После подключения в заголовке задач появится переключатель сайтов, а вариант **Все сайты** объединит задачи.

Если Jira не используется, скройте её в списке источников через [Настройки → Задачи](/docs/reference/settings).

Работа с Jira
-------------

* После включения источников панель показывает задачи GitHub, Linear и Jira в общем списке.
* Откройте задачу, чтобы увидеть описание, комментарии и метаданные. Состояние через доступные переходы, приоритет, исполнитель и пользовательские поля редактируются на месте.
* Комментарий можно добавить через форму в карточке.
* При создании worktree из задачи Jira название заполняется автоматически, а задача остаётся связанной с worktree и последующей проверкой.
* Для каждого репозитория Orca запоминает последний источник задач.

Где хранится токен

Токен Atlassian API шифруется через связку ключей операционной системы и хранится локально. Он используется только для запросов к настроенному сайту Jira. Если Orca больше не нужна, отзовите токен в настройках Atlassian.
