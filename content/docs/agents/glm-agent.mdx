---
title: "Как использовать GLM-5.2 в Orca ADE"
description: "Настройка Claude Code и других CLI-оболочек для запуска GLM-5.2 в worktree Orca."
---


В этой статье описана настройка Claude Code и других CLI-оболочек для запуска GLM-5.2 в worktree Orca.

GLM-5.2 работает в Orca через уже используемую вами оболочку агента. Настройте модель в Claude Code, OpenCode, Cline, Kilo Code, Roo Code, Droid, OpenClaw или другом консольном агенте, затем запустите этот агент из списка Orca.

Orca предоставляет изолированный worktree, панели терминала, вкладку браузера, проверку изменений и управление сессиями. Доступ к модели обеспечивают ваша [подписка Z.ai CodePlan](https://z.ai/subscribe) и конфигурация агента.

Предварительное требование

Перед настройкой GLM-5.2 нужна активная [подписка Z.ai CodePlan](https://z.ai/subscribe) с доступом к GLM Coding Plan. Для оболочек, совместимых с OpenAI API, также потребуется ключ Z.ai API. Orca не предоставляет и не перепродаёт доступ к GLM.

Источник настроек

Параметры ниже соответствуют [актуальному руководству Z.ai по моделям](https://docs.z.ai/devpack/latest-model). Проверяйте эту страницу, если нужны последние сведения со стороны провайдера.

Claude Code
-----------

Claude Code читает переопределения моделей из `~/.claude/settings.json`. Чтобы использовать GLM-5.2 в Orca:

1. Откройте `~/.claude/settings.json`.
2. Добавьте или обновите приведённый ниже блок `env`.
3. Перезапустите сессии Claude Code в Orca, чтобы загрузить новое окружение.
4. Выполните `/status` в Claude Code и проверьте активную модель.

```
{
  "env": {
    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "1000000",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "glm-4.5-air",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "glm-5.2[1m]",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-5.2[1m]"
  }
}
```

Суффикс `[1m]` включает вариант GLM-5.2 с контекстом в 1 миллион токенов. Оставьте для `CLAUDE_CODE_AUTO_COMPACT_WINDOW` значение `1000000`, чтобы окно сжатия Claude Code соответствовало этому размеру контекста. Если Claude Code сообщает, что модели `[1m]` не существует, обновите Claude Code и повторите попытку.

Для задач программирования Z.ai рекомендует установить уровень усилий Claude Code `max` командой `/effort`. Низкие уровни усилий Claude Code соответствуют высокому уровню GLM-5.2, а `xhigh`, `max` и `ultracode` соответствуют максимальному.

OpenCode, Cline, Kilo Code, Roo Code и Droid
-------------------------------------------

Для оболочек агента с поддержкой провайдера, совместимого с OpenAI API:

1. Откройте настройки оболочки внутри Orca или отдельно.
2. Выберите провайдера, совместимого с OpenAI API, либо Z.ai, если он доступен в списке.
3. Укажите базовый URL `https://api.z.ai/api/coding/paas/v4`.
4. Добавьте ключ Z.ai API.
5. Укажите имя пользовательской модели `glm-5.2`.
6. Если доступно соответствующее поле, установите размер контекстного окна `1000000`.
7. Отключите поддержку изображений, если в документации оболочки она не заявлена для этого способа подключения.

Сохраните настройки и запустите оболочку из списка агентов Orca. В выбранном worktree будет запущен тот же настроенный CLI.

OpenClaw
--------

Если OpenClaw не позволяет выбрать GLM-5.2 в списке моделей провайдера, добавьте модель вручную в `~/.openclaw/openclaw.json`.

Добавьте `glm-5.2` в `models.providers.zai.models`:

```
{
  "id": "glm-5.2",
  "name": "GLM-5.2",
  "reasoning": true,
  "input": ["text"],
  "cost": {
    "input": 0,
    "output": 0,
    "cacheRead": 0,
    "cacheWrite": 0
  },
  "contextWindow": 1000000,
  "maxTokens": 131072
}
```

Затем задайте основную модель по умолчанию:

```
{
  "model": {
    "primary": "zai/glm-5.2",
    "fallbacks": ["zai/glm-4.7"]
  }
}
```

Добавьте модель в `agents.defaults.models`:

```
{
  "models": {
    "zai/glm-5.2": { "alias": "GLM" },
    "zai/glm-4.7": {}
  }
}
```

Перезапустите шлюз OpenClaw:

```
openclaw gateway restart
```

Запустите OpenClaw из Orca или выполните `openclaw tui` в терминале Orca, чтобы убедиться, что GLM-5.2 активна.

Добавление другой оболочки GLM-5.2
---------------------------------

Если нужная оболочка пока не встроена в Orca, добавьте её как собственного CLI-агента:

1. Откройте [Настройки → Агенты](/docs/reference/settings).
2. Нажмите **Добавить собственного агента**.
3. Укажите исполняемый файл оболочки или команду запуска.
4. Сохраните агента и запустите его из списка в любом worktree.

Общее правило: настройте GLM-5.2 там, где оболочка хранит параметры провайдера и модели, а затем позвольте Orca запустить эту оболочку в нужном worktree.
