Cursor CLI работает как консольный агент Cursor. Orca поддерживает его запуск из списка агентов, определение состояния через OSC и перезапуск после завершения процесса.

Установка
---------

1. Установите Cursor CLI по [инструкции Cursor](https://cursor.com/cli).
2. Один раз войдите в аккаунт.
3. Orca автоматически найдёт CLI в `PATH`.

Запуск
------

Выберите **Cursor** в списке агентов. Orca запустит CLI в текущем worktree. Терминальный интерфейс Cursor отправляет события состояния, по которым Orca обновляет индикатор агента.

Выбор модели
------------

Модель выбирается в настройках самого Cursor. Orca не переопределяет этот параметр, поэтому настраивать его нужно внутри CLI.
