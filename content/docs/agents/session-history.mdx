На правой боковой панели Orca можно просматривать и возобновлять прошлые сессии Claude, Codex, Cursor, Gemini и других агентов.

Orca сканирует сохранённые на диске расшифровки сессий, которые оставляют поддерживаемые CLI, и показывает их на панели **История сессий агентов**. Выберите сессию и нажмите **Возобновить**. Orca откроет новый терминал и выполнит команду возобновления с тем же `cwd` и идентификатором сессии. Вводить параметр `--resume` вручную не потребуется.

Открытие панели
---------------

Откройте правую боковую панель и перейдите на вкладку **Агенты**. В заголовке панели будет указано "История сессий агентов".

Рядом отображается счётчик наподобие `Показано 12 · Недавних 47` и поле поиска. Список можно фильтровать по названию сессии, рабочему каталогу, ветке, модели и фрагменту диалога.

Область поиска
--------------

Переключатель в верхней части панели определяет, какие сессии показывать:

* **Рабочее пространство**: сессии текущего рабочего пространства или worktree, в зависимости от активного контекста.
* **Проект**: сессии, относящиеся к активному проекту Orca.
* **Все**: все найденные на этом компьютере сессии всех агентов.

Из удалённых рабочих пространств можно просматривать локальную историю, но возобновлять сессии разрешено только в локальных. Для удалённого worktree Orca покажет это ограничение на панели.

Параметры отображения
---------------------

В меню рядом с поиском выбираются сканируемые агенты, сортировка и группировка:

* **Агенты**: включение и отключение отдельных CLI (Claude, Codex, Cursor, Gemini, Hermes, Pi, Copilot, OpenCode, Grok, OpenClaw, Droid и Rovo Dev). Отключённые агенты не сканируются.
* **Сортировка**: по времени последнего обновления или создания.
* **Группировка**: по проекту, папке (отдельный заголовок для каждого `cwd`) или агенту.
* **Скрывать пустые сессии**: исключает сессии без сохранённых сообщений.

Возобновление сессии
--------------------

Нажмите на строку сессии, чтобы открыть подробности: рабочий каталог, ветку, модель, число сообщений, общее количество токенов, исходный запрос и последние сообщения. Сессию также можно возобновить, перетащив активную строку в рабочее пространство. В меню строки доступны следующие действия:

* **Возобновить**: открывает новый терминал в каталоге `cwd` и выполняет команду агента, например `claude --resume <id>`, `codex resume <id>`, `cursor-agent --resume <id>` или `acli rovodev run --restore <id>`. Для Codex также восстанавливается `CODEX_HOME`, если эта переменная была задана в исходной сессии.
* **Копировать команду возобновления**: копирует ту же команду для запуска во внешнем терминале.
* **Копировать ID сессии** и **Копировать путь к журналу**: пригодится для сценариев и прикрепления расшифровок к отчётам об ошибках.
* **Открыть журнал** и **Показать журнал**: открывает исходный файл расшифровки в Orca или показывает его в файловом менеджере системы.
* **Открыть cwd**: открывает рабочий каталог сессии как рабочее пространство.

Для возобновления нужно локальное рабочее пространство

Команда агента выполняется на компьютере, где запущена Orca. Если вы подключены к удалённому рабочему пространству, перед нажатием **Возобновить** вернитесь в локальное. Другой вариант: скопируйте команду и самостоятельно выполните её на удалённой машине.

Откуда берутся расшифровки
--------------------------

Orca читает собственное хранилище каждого агента: `~/.codex/sessions` для Codex, историю `~/.claude` для Claude, журнал сессий Cursor, прежние файлы сессий OpenCode или базу `~/.local/share/opencode/opencode.db` и другие источники. Включать эту возможность отдельно не нужно. Если CLI сохраняет расшифровку, она появится на панели после следующего сканирования. Для немедленного обновления нажмите **Обновить историю сессий**.
