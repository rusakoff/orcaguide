Orca поддерживает принятые в Claude Code и Codex соглашения о хуках и файлах памяти. Она читает эти настройки, соблюдает их и предоставляет интерфейс для тех возможностей, которые уместны в среде разработки.

Хуки репозитория
----------------

Orca читает конфигурацию `.claude/` и `.codex/` в каждом репозитории. Существующие хуки запускаются, когда Orca открывает агента в worktree этого репозитория.

Хуки настройки worktree
-----------------------

Можно автоматически выполнять команды после создания worktree, например `pnpm install`, `direnv allow` или сценарий восстановления файлов `.env`. Настройка находится в разделе [Настройки → Репозиторий → Хуки](/docs/reference/settings).

Файлы памяти
------------

Orca не изменяет файлы `CLAUDE.md` для Claude и `AGENTS.md` для Codex, расположенные в корне репозитория или вложенных каталогах. Они принадлежат агентам. Orca показывает их в проводнике вместе с остальными файлами и позволяет редактировать во встроенном редакторе.

Работа после перезапуска
------------------------

Адреса хуков записываются на диск: `{userData}/agent-hooks/endpoint.env` в POSIX-системах и `endpoint.cmd` в Windows. При каждом вызове хука файл подключается заново. Поэтому длительные сессии агентов продолжают обращаться к действующему серверу Orca даже после перезапуска приложения, а старый PTY не отправляет POST-запросы на закрытый порт.

В Orca CLI есть комментируемое поле состояния worktree, которое агенты могут обновлять самостоятельно. Подробнее: [Контрольные точки worktree](/docs/cli/worktree-checkpoints).
