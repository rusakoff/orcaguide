На этой странице перечислены агенты, которые Orca поддерживает изначально, и описано подключение собственного агента.

Orca работает с **любым CLI-агентом**, поскольку список агентов запускает обычный процесс в терминале. Перечисленные ниже агенты заранее настроены во встроенном списке и запускаются или устанавливаются одним нажатием. Для каждого указаны доступные интеграции: хуки, состояние, учёт использования и смена аккаунтов.

Разрешения по умолчанию
-----------------------

При первом запуске Orca подставляет для каждого поддерживаемого CLI параметр обхода запросов разрешений: `--dangerously-skip-permissions` для Claude, `--dangerously-bypass-approvals-and-sandbox` для Codex, `--yolo` для Gemini, Cursor, Crush, Kimi, Rovo Dev, Hermes, GitHub Copilot и Command Code, а также аналогичный параметр для остальных агентов, если он предусмотрен. Это рассчитано на одноразовые worktree. Агент может свободно экспериментировать в отдельной рабочей копии, а перед слиянием вы можете перенести нужные изменения или полностью отклонить diff.

В разделе **Настройки → Агенты → Разрешения агентов** можно переключить всех агентов без собственной конфигурации между режимами **Yolo** и **Ручной**. Если вы ранее изменили аргументы запуска или окружение отдельного агента, Orca не будет менять его настройки при глобальном переключении.

Чтобы вернуть запросы разрешений только для одного агента, измените его стандартные аргументы или окружение в настройках. Непустое пользовательское значение считается явным переопределением, поэтому дальнейшие изменения общего режима разрешений не затронут этого агента.
