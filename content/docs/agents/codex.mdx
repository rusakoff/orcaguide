Codex работает как консольный агент OpenAI. Orca глубоко интегрирована с Codex: учёт использования, смена аккаунта и перезапуск сохраняют данные выбранного аккаунта.

Установка
---------

1. Установите Codex по инструкции OpenAI.
2. Войдите в аккаунт из любого терминала.
3. Orca прочитает данные аккаунтов и учётные данные из `~/.codex`.

Запуск
------

Выберите **Codex** в списке агентов. Orca запустит `codex`, назначит текущий worktree рабочим каталогом и использует выбранный аккаунт для авторизации.

Быстрая смена аккаунта
----------------------

Многие пользователи Codex подключают несколько аккаунтов, чтобы расширить доступные лимиты. Переключатель Orca меняет активный аккаунт без повторного входа и правки конфигурации. Подробнее: [Быстрая смена аккаунтов Codex](/docs/agents/codex-hot-swap).

Кнопка перезапуска
------------------

После завершения Codex кнопка перезапуска снова запускает агента с тем же аккаунтом. Если вы сменили аккаунт во время сессии и хотите использовать новый, сначала выберите его, затем перезапустите агента.

Использование и лимиты
----------------------

Orca читает локальные данные об использовании Codex для активного аккаунта и показывает их в строке состояния. Подробнее: [Учёт использования и лимитов](/docs/agents/usage-tracking).

Codex в Windows через WSL
-------------------------

В Windows Orca может запускать Codex из основной системы или из дистрибутива WSL. Добавьте аккаунт Codex из WSL через переключатель аккаунтов. Orca создаст для него изолированный домашний каталог внутри дистрибутива по адресу `~/.local/share/orca/codex-accounts/<id>/home` и сопоставит его с путём основной системы вида `\\wsl.localhost\<дистрибутив>\...`, чтобы читать данные авторизации. Запуск, смена аккаунта и получение данных о лимитах будут выполняться через выбранный дистрибутив. Если в нём не установлен Codex, окно **Добавить аккаунт** сообщит, в каком дистрибутиве не найден исполняемый файл.
