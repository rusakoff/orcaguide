Orca может работать с любым консольным агентом. Его добавление занимает несколько шагов.

![Добавление произвольного CLI-агента: укажите исполняемый файл, и агент появится в списке](https://www.onorca.dev/whats-new/posters/any-cli-agent.jpg)

Добавление произвольного CLI-агента: укажите исполняемый файл, и агент появится в списке

Добавление агента
----------------

1. Откройте [Настройки → Агенты](/docs/reference/settings).
2. Нажмите **Добавить собственного агента**.
3. Укажите название, путь к исполняемому файлу или команду и аргументы по умолчанию.
4. При необходимости добавьте хук запуска: команду оболочки, которую Orca выполнит перед запуском агента, например `source .envrc`.

Что будет доступно
------------------

* Агент появится в списке каждого терминала.
* Рабочим каталогом всегда будет текущий worktree.
* После завершения процесса появится кнопка перезапуска.
* Если CLI отправляет заголовки OSC, Orca будет показывать индикатор состояния.

Настройка индикатора состояния
------------------------------

Orca определяет состояния "работает" и "ожидает" по обновлениям заголовка OSC. Если агент отправляет заголовки наподобие `working` или `idle`, Orca распознает их автоматически. Если таких событий нет, терминал продолжит работать как обычно, но без индикатора состояния.

Через список агентов можно запускать и обычные `bash` или `zsh`. Это удобно, когда нужна оболочка с контекстом текущего worktree, но без агента.
