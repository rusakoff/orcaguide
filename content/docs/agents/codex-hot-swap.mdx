Пользователи нередко подключают несколько аккаунтов Codex, чтобы увеличить доступный объём токенов. Orca позволяет сменить активный аккаунт одним нажатием, без повторного входа и редактирования конфигурации. Тот же порядок действий работает с аккаунтами Claude Code.

![Меню выбора аккаунта Codex в строке состояния](https://www.onorca.dev/whats-new/posters/codex-account-switcher.jpg)

Добавление аккаунтов
--------------------

1. Хотя бы один раз войдите в каждый аккаунт Codex из терминала, чтобы данные авторизации появились в `~/.codex`.
2. Откройте [Настройки → Агенты → Аккаунты Codex](/docs/reference/settings).
3. Orca покажет все найденные аккаунты, их использование и текущий лимит.
4. Присвойте каждому аккаунту понятную подпись, например "личный" или "рабочий".

Смена аккаунта
--------------

Нажмите на индикатор Codex в строке состояния, чтобы открыть меню аккаунтов. Выберите нужный аккаунт. Все новые сессии Codex будут использовать его. Уже запущенные сессии продолжат работать с прежним аккаунтом до перезапуска.

Правила и особенности
---------------------

* Переключение происходит сразу: Orca меняет указатель на активные учётные данные, а не выполняет повторную авторизацию.
* Запущенные процессы Codex сохраняют текущий аккаунт до перезапуска.
* Показатели использования в строке состояния относятся к активному аккаунту.
* Кнопка перезапуска использует аккаунт, который был активен в момент перезапуска.

Аккаунты Claude Code
--------------------

Переключатель аккаунтов Claude работает так же. Отличается только каталог с данными: `~/.claude`.
