Claude Code работает как консольный агент Anthropic. Orca запускает его как полноценного терминального агента: учитывает аккаунт при создании сессии, отслеживает использование и позволяет быстро переключаться между аккаунтами.

Установка
---------

1. Установите Claude Code командой `npm i -g @anthropic-ai/claude-code` или по инструкции Anthropic.
2. Один раз войдите в аккаунт из любого терминала.
3. Orca автоматически найдёт каталог `~/.claude`. Дополнительная настройка не нужна.

Запуск
------

Откройте терминал в любом worktree и выберите **Claude Code** в списке агентов. Orca запустит его в рабочем каталоге этого worktree и подключит обработчик строки состояния. Обработчик отправляет события заголовка OSC, по которым Orca отображает состояние агента.

Использование и лимиты
----------------------

Orca читает локальные данные об использовании из `~/.claude` и показывает в строке состояния текущий расход и приближение к лимиту. Подробнее: [Учёт использования и лимитов](/docs/agents/usage-tracking).

Быстрая смена аккаунта
----------------------

Orca поддерживает несколько аккаунтов Claude и позволяет переключаться между ними одним нажатием, как в случае с Codex. Аккаунт можно сменить даже при запущенных сессиях Claude. Orca не допускает одновременного запуска нескольких обновлений авторизации. Подробнее: [Быстрая смена аккаунтов Codex](/docs/agents/codex-hot-swap). Для Claude порядок действий такой же.

Хуки и память
-------------

Claude Code поддерживает хуки и файлы памяти на уровне репозитория. Они доступны в разделе [Хуки и память агентов](/docs/agents/hooks-memory).
