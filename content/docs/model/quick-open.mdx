title: "Быстрое открытие и палитра перехода"

---


Для перехода между большим числом worktree в Orca есть палитра перехода и окно быстрого открытия. Оба инструмента рассчитаны на клавиатуру.

Быстрое открытие (Cmd-P)
-----------------------

Эта команда ищет файлы в текущем worktree. Введите часть названия, и Orca отсортирует результаты по недавнему использованию и точности совпадения, затем откроет файл в новой вкладке. Игнорируемые Git файлы тоже попадают в результаты, но показываются после отслеживаемых. Часто открываемые сборочные результаты и файлы окружения остаются доступны, не занимая верхние строки.

Палитра перехода между worktree (Cmd-J)
---------------------------------------

Палитра ищет сразу по всем worktree и вкладкам. В пустом поле отображается подсказка _репозиторий/worktree_. Можно вводить любую часть, и Orca отфильтрует результаты. После начала ввода поиск включает неархивированные worktree, даже если текущие фильтры боковой панели их скрывают.

В результатах отображаются:

* **Недавние worktree**: верхний раздел при пустом запросе, отсортированный по времени последнего перехода и ограниченный удобным для просмотра числом строк.
* Проекты и группы репозиториев, к которым можно перейти по названию.
* Все worktree, сгруппированные по репозиторию после начала ввода.
* Worktree, найденные по сохранённому названию или номеру pull request GitHub (`#123`) либо merge request GitLab (`!123`), если эти сведения уже доступны.
* Все открытые вкладки, сначала в текущем worktree, затем во всех остальных.

Сочетание `Shift-Enter` открывает worktree в новой панели вместо замены содержимого текущей.

Если запрос не совпал с существующим worktree, палитра предложит строку **Создать worktree** и использует введённый текст как название. При наличии совпадений сначала выбирается существующий результат, поэтому `Enter` продолжит выполнять переход.

Сочетания клавиш можно изменить в разделе [Настройки → Сочетания клавиш](/docs/reference/settings).
