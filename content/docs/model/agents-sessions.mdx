Orca показывает состояние каждой сессии агента и даёт перезапустить завершившийся процесс. Индикаторы видны на вкладках и карточках worktree.

**Сессия агента** означает один CLI-агент, запущенный в одном терминале одного worktree. Orca отслеживает его состояние, поэтому видно, какие сессии работают, а какие ожидают, без перехода на каждую вкладку.

![Состояние агента на каждой карточке worktree: жёлтый индикатор во время работы и зелёный после завершения](https://www.onorca.dev/whats-new/posters/agent-statuses.jpg)

Индикаторы состояния
---------------------

На каждой вкладке отображается небольшая точка:

* **Пульсирующая зелёная**: агент активно работает, а его терминальный интерфейс не находится в состоянии ожидания.
* **Жёлтая**: агент ожидает вашего ввода.
* **Серая**: агент бездействует.
* **Без точки**: в терминале открыта обычная оболочка, а не распознанный CLI-агент.

Состояние определяется по последовательностям заголовка OSC, которые отправляют Claude Code, Codex и некоторые другие агенты.

Панель агентов
--------------

На каждой карточке worktree в боковой панели показаны сессии агентов с теми же цветными индикаторами. Можно сразу увидеть состояние всех агентов, не раскрывая карточки. Непросмотренные строки остаются полужирными, а дополнительный индикатор выводит наверх worktree, требующие внимания.

Панель включена по умолчанию и не имеет отдельного переключателя. Если точек нет, CLI в этой сессии не отправляет известные Orca заголовки OSC. Запускайте его через список агентов, а не вводите имя исполняемого файла вручную.

Параметры запуска
-----------------

Orca заранее добавляет каждому поддерживаемому агенту параметр автономной работы: `--dangerously-skip-permissions` для Claude, `--dangerously-bypass-approvals-and-sandbox` для Codex, `--yolo` для Gemini и аналогичные параметры для остальных агентов. Сам worktree выполняет роль песочницы, поэтому запросы разрешения для каждого инструмента не прерывают работу.

Чтобы изменить параметры агента, откройте **Настройки → Агенты**, раскройте его строку и отредактируйте **Аргументы запуска**. Orca запомнит значение для следующих запусков. Кнопка **Сбросить** возвращает исходный параметр.

Кнопка перезапуска
------------------

После штатного или аварийного завершения агента на вкладке появляется кнопка **Перезапустить**. Она запускает того же агента в прежнем рабочем каталоге. Для Codex сохраняется и текущий аккаунт. Подробнее: [Быстрая смена аккаунтов Codex](/docs/agents/codex-hot-swap).

Жизненный цикл сессии
---------------------

1. **Запуск**: выберите агента в списке, и Orca запустит CLI.
2. **Работа**: заголовки OSC обновляют состояние, а терминал показывает вывод с поиском, копированием и оформлением Ghostty.
3. **Ожидание**: Orca замечает переход из работы в ожидание и отправляет [уведомление о завершении агента](/docs/reference/notifications).
4. **Выход**: процесс завершается, после чего появляется кнопка перезапуска.

Точные правила определения состояния описаны для команды `terminal wait --for tui-idle` в разделе [Orca CLI](/docs/cli/overview).
