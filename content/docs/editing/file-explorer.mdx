Проводник слева показывает файлы текущего worktree и следит за изменениями на диске. Создание, переименование, удаление и перемещение используют обычные операции файловой системы. Изменения агента появляются в дереве без ручного обновления.

Перетаскивание внешних файлов
-----------------------------

* Перетащите файлы из Finder или Проводника в дерево, чтобы скопировать их.
* Перетащите изображение в редактор Markdown, чтобы вставить его в позицию курсора.
* Перетащите файлы в терминал агента, чтобы вставить их пути в строку ввода.
* В [worktree по SSH](/docs/reference/ssh) перетаскивание тоже работает. Orca сначала загрузит файл на удалённый компьютер, поэтому агент получит настоящий путь в его файловой системе.

Состояние Git
-------------

Цвет файла показывает его состояние в Git: неотслеживаемый, изменённый, добавленный в индекс или игнорируемый. В контекстном меню доступны обычные действия, включая отмену изменений, добавление в индекс и переименование.

Выберите **Копировать** в контекстном меню одного файла, чтобы поместить сам файл в буфер обмена операционной системы. Для worktree по SSH Orca сначала временно сохранит удалённый файл локально, а затем добавит ссылку на него в буфер. Удалённые папки таким способом не копируются.

Поиск в папке
-------------

Выберите **Найти в папке** в контекстном меню каталога, чтобы открыть поиск с уже заданной областью. Можно также выделить папку в проводнике и нажать `Cmd-Shift-F` в macOS или `Ctrl-Shift-F` в Windows и Linux.
