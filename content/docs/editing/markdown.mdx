---
title: "Визуальный редактор Markdown"
description: "Редактирование Markdown с меню команд, предпросмотром, ссылками и оглавлением."
---


По умолчанию Markdown открывается в визуальном редакторе с меню команд и автодополнением внутренних ссылок. Изображения и блоки кода отображаются прямо в документе. Сочетание `Cmd-Shift-M` переключает файл на исходный текст в Monaco.

![Визуальный редактор Markdown с меню команд, встроенным предпросмотром и автодополнением ссылок](https://www.onorca.dev/whats-new/posters/orca-markdown-editor.jpg)

Меню команд
-----------

Введите `/` в пустой строке, чтобы открыть меню заголовков, списков, блоков кода, примечаний, изображений, диаграмм Mermaid и сворачиваемых блоков.

Команда `/toggle-text` создаёт сворачиваемую заметку, а `/toggle-h1` оформляет её заголовок как заголовок первого уровня. Orca сохраняет оба варианта в переносимом формате Markdown с `<details>` и `<summary>`, поэтому файл корректно отображается вне Orca.

Внутренние ссылки
-----------------

Введите `[[`, чтобы начать ссылку в стиле wiki. Orca предложит пути к файлам текущего worktree и вставит относительную ссылку.

Поиск
-----

Поиск в визуальном редакторе работает с отображаемым текстом, а не с исходной разметкой. Запрос "Install" найдёт заголовок независимо от того, записан ли он как `# Install` или `<h1>Install</h1>`.

Комментарии при проверке
------------------------

Во время проверки Markdown выделите отображаемый текст и добавьте комментарий, не переходя к исходной разметке. Orca привязывает заметку к выбранному диапазону исходника и продолжает показывать её при редактировании документа.

Метаданные
----------

Блоки метаданных YAML и TOML по умолчанию видны в редакторе и предпросмотре. Документация и публикации для статических сайтов показывают свои параметры без перехода к исходному тексту. В меню **Дополнительные действия** (`…`) выберите **Скрыть метаданные**, если нужен только основной текст. Там же их можно снова показать. Настройка действует отдельно для каждого файла.

Оглавление
----------

В длинном документе нажмите кнопку **Оглавление** со значком дерева в заголовке редактора. Слева откроется закреплённый список заголовков. Нажатие переходит к нужному разделу, а сворачивание уровней упрощает работу с глубокой структурой. Оглавление доступно в визуальном режиме и режиме предпросмотра.
