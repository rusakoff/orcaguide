# План SEO-работ для Orca Guide

## Статус реализации — 25 июля 2026

Рекомендации, которые зависят от репозитория, реализованы:

- добавлены `Organization`, `WebSite`, `TechArticle`/`WebPage` и `BreadcrumbList`;
- добавлены редактор, дата обновления, официальный первоисточник и связанные материалы;
- созданы страницы «О проекте» и «Редакционная политика»;
- усилены главная, `/docs` и короткие справочные страницы;
- добавлены security headers, `www`-редирект, OG-изображение и sitemap `lastmod`;
- расширены `llms.txt` и `llms-full.txt`;
- добавлены IndexNow key-файл и команда `npm run seo:indexnow`;
- увеличены touch targets, уменьшена нагрузка Метрики на первый рендер;
- настроены AVIF/WebP и недельный кэш оптимизированных внешних изображений;
- импортёр сохраняет локальные дополнения к слабо раскрытым upstream-страницам;
- Biome обновлён до установленной версии, lint, TypeScript и production build проходят.

Остаются внешние операции, которые нельзя достоверно выполнить из репозитория:

1. Выпустить TLS-сертификат для `www.orcaguide.ru` на стороне DNS/хостинга. Код уже выполняет `308` после успешного TLS-соединения.
2. Развернуть текущую версию сайта и проверить, что production больше не расходится с рабочей копией.
3. После деплоя выполнить `npm run seo:indexnow`.
4. Предоставить доступ к Google Search Console/GA4 и дождаться CrUX-данных для проверки индексации, CTR и полевых CWV.
5. После накопления данных провести SERP-кластеризацию и аудит ссылочного профиля.

## Критерии приёмки

- `www` отвечает валидным сертификатом и одним `308` на apex.
- На всех публичных страницах schema проходит валидатор без ошибок и отражает видимый контент.
- У каждой статьи есть ответственный редактор и реальная дата проверки.
- Security headers присутствуют на HTML-ответах.
- INP по CrUX ≤ 200 мс; LCP ≤ 2,5 с; CLS ≤ 0,1.
- Все sitemap URL возвращают `200`, содержат self-canonical и актуальный `lastmod`.
- Нет страниц без контекстной входящей ссылки.
- Повторный `npm run types:check` и `npm run build` проходят.
